技术实现方案

图纸解析层

  • DWG解析：ODA File Drawings SDK 提取几何实体与标注
  • PDF/图片：OpenCV 预处理 + 版面分析
  • 标题栏OCR：PaddleOCR 识别图号、名称、材质、比例
  • 图层分离：按线型/颜色区分轮廓线、标注线、中心线

AI识别层

  • 构件检测：YOLOv8 微调，识别焊架/箱体/法兰/异形等构件族
  • 参数提取：几何计算 + 规则引擎，自动测算重量/焊缝长度
  • 材质识别：标题栏OCR + 材料表关联，映射材质系数
  • 复杂度评级：图元密度 + 工序数 + 特征点，自动评级1-5

成本预测层（功能2）

  • 工时估算：多元线性回归模型，输入识别出的构件参数，输出预估工时+置信区间
  • 成本拆解：8项成本自动核算（钢材/焊材/人工/外协/设备/余料/管理/安装）
  • 市场联动：钢材价格实时对接ERP，外协单价参考历史中标价，宏观经济指标调整系数
  • 小样本优化：新构件类型采用迁移学习，基于相似构件族预训练模型微调
AI工时估算模型 — 多元线性回归

模型公式

预估工时 = β₀ + β₁×重量 + β₂×材质系数
        + β₃×复杂度 + β₄×工序数
        + β₅×(1/批量) + β₆×历史均值

β₀=1.5, β₁=0.032, β₃=2.5
β₄=1.8, β₅=8.5, β₆=0.3
残差σ=2.8h，95%CI = 预估 ± 1.96σ

System Prompt（核心约束）

你是一个专业的成本分析助手。

【角色定位】
只负责分析和解释异常原因，不做最终决策。

【输出约束】
1. 必须基于提供的数据，禁止编造数据
2. 数据不足时明确说明"数据不足，无法判断"
3. 禁止涉及责任认定和人员处罚建议
4. 每次输出末尾必须添加免责声明
5. 引用数据必须标注来源字段

【输出格式】
根因分析：[3条以内，按重要性排序]
改进建议：[2条以内，可落地]
数据引用：[来源字段列表]
免责声明：本分析由AI生成，仅供参考

输出校验机制

  • 数据引用校验：检查输出中引用的数值是否存在于输入中
  • 免责声明强制：缺失则自动追加标准免责声明
  • 敏感词过滤：责任认定/处罚类词汇命中则拦截重生成
  • 人工确认强制：所有LLM输出默认"待确认"状态，确认后才生效
  • Few-shot示例：提供2个标准分析示例，引导输出格式
边界规定：LLM仅用于根因分析和改进建议，不参与成本计算、不做审批决策、不自动修改数据。所有输出必须经过人工确认。
